# Contact Us Form Component (HTML & Tailwind CSS)

A clean, responsive Contact Us form UI component built with **HTML5** and **Tailwind CSS**. Designed to practice form layout structure, input field styling, spacing hierarchy, and utility-first responsive design.

## Features
- **Centered Card Layout:** Elevated white form container set against a soft neutral background.
- **Structured Input Grid:** Side-by-side first and last name fields paired with full-width email and feedback textarea inputs.
- **Accessible Form Controls:** Styled terms and conditions checkbox and full-width primary submit button.
- **Responsive Design:** Adapts cleanly across mobile, tablet, and desktop screen sizes.

## Tech Stack
- **HTML5**
- **Tailwind CSS**
